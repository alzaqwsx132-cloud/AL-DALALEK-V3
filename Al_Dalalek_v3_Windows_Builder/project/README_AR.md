# نظام الدلالك — نسخة تطوير React / TypeScript / Supabase

هذا تحديث للمشروع المرفق، مع المحافظة على منطق حفظ السندات الموجود ودون تطبيق عمليات ترقيم قديمة أو تعديلات مباشرة على قاعدة بيانات المستخدم.

اقرأ **STATUS_AR.md** أولاً؛ يذكر المميزات المعدلة والحواجز المهمة لبقية المميزات.

## التشغيل

- يتطلب Node.js 20 أو أحدث واتصالاً بالحزم أثناء التثبيت.
- جهّز ملف `.env` بالقيم العامة المناسبة لـ Supabase. لا تضف مفتاح `service_role` إلى مشروع Vite.
- شغّل `npm ci`، ثم `npm run typecheck` و`npm run build`.
- شغّل الاختبارات الآمنة `npm run test:logic`.

## ما يحتاج مطور Supabase

`supabase/diagnostics/READ_ONLY_PRECHECK.sql` يوضح بنية جدول السندات ودواله الحالية. ملف الترحيل الاختياري في `optional_migrations` **مقصود أن يفشل** إذا شغّلته الآن؛ لا تُزل هذا القيد قبل مراجعة المخطط والمصادقة الفعلية.

## تنبيه أمني

تسجيل الدخول في المصدر القديم يعتمد على `app_users` بصلاحيات `anon`. إخفاء الأزرار والتجهيزات الأمامية ليس حماية لبيانات المخزون. قبل إطلاق هذا المشروع، يجب نقل التحقق من المستخدم وصلاحياته إلى الخادم وإعداد سياسات RLS، ثم تدوير كلمات المرور الافتراضية الموجودة في قواعد البيانات القديمة.
